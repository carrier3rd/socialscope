# History rewrite, Nov 19 2026

On Nov 19, 2026 the history of this repository was rewritten at the owner's request, to remove the owner's personal
name and email address from public files and commit metadata. Every commit got a new id. Nothing else changed:
file contents are identical apart from the name (now "the owner"), and every author and commit date is kept, so the
timestamps that prove predictions came before their data still hold.

Commit ids cited in the docs were updated to the new ids in the commit that added this file. An id written in a
results file that no longer matches a commit here is an old id from before the rewrite. The old-to-new map is kept
privately by the owner and can be checked on request.
